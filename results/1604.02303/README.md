## The problem

The source is Potapov and Semukhin, [*Decidability of the Membership Problem for
2×2 integer matrices*](https://arxiv.org/abs/1604.02303). An instance gives labelled,
nonsingular 2×2 integer generators and a target matrix. The solver returns an ordered
word of labels whose exact product is the target. The checker validates labels and
multiplies four integer entries per factor; it never reads the planted answer.

Generation is inverse, not search: sample a generator word and multiply it to obtain
the target. Internally the generators are simultaneous unimodular conjugates of
`[[B,r+B^k*d],[0,1]]`, using distinct hidden radix digits `0 <= d < B` and an
offset `r` divisible by `B-1`. All digits are generated before the witness is sampled,
so there is no separate planted-element population. The common residue modulo `B^k`
is deliberate: testing whether `G^-1*Target` is integral leaves every possible prefix
alive through depth `k`, rather than revealing the next planted label.

## Why Track B

Section 2 fixes membership as equality to a finite generator product. Theorem 1 in
Section 3 proves decidability for all nonsingular 2×2 integer generators; its following
complexity remark gives an EXPSPACE upper bound. The proof limits non-unimodular factors
using `log_2 |det(Target)|` and reduces the remaining choices to regular-language
emptiness. Section 3.1, Proposition 7 and Corollary 8 make the `GL(2,Z)` case decidable
through unique canonical `X,N,S,R` words. The introduction also records polynomial
algorithms for the one-generator orbit problem and commutative generators. These are
easy regimes and rule out a Track-A claim.

For this bounded, determinant-forced subclass, the successful reference method is
bidirectional meet-in-the-middle over matrix products. Its complexity is
`O(n^(ceil(k/2)))` exact states. At the named shipping candidate (`n=14`, `k=10`,
48-bit radix), eight exact runs averaged **871,963 product nodes, about 10,463,560
scalar arithmetic operations, and 5.341744 s** each.
The compact route notices that all generator differences occupy one rank-one line,
normalizes its endpoints to digits `0` and `B-1`, and reads the target coordinate in
base `B`; the implementation counts **181 exact arithmetic operations**. Thus an
efficient structured decoder exists and is disclosed—this family tests whether a
no-tool solver finds and executes that compression, not structural complexity.

## Worked demo

With `make_instance(n=4, word_length=3, digit_bits=5, seed=7)`, `render` returns:

```text
Find a membership witness in a semigroup of nonsingular 2 x 2 integer matrices.

Definitions. Multiplication is ordinary left-to-right matrix multiplication over the integers. The semigroup generated by the displayed matrices consists of the identity and every finite product of one or more generators; order matters and a generator may be repeated. A membership witness is the ordered word of generator labels whose product equals the target exactly. Matrix rows and entries are shown as [[a,b],[c,d]].

There are 4 generators. Their labels are g00 through g03.
  g00 = [[-306948799, 2592012300], [-36349200, 306948826]]
  g01 = [[-66509119, 561632780], [-7876080, 66509146]]
  g02 = [[-162684991, 1373784588], [-19265328, 162685018]]
  g03 = [[-6399199, 54037900], [-757800, 6399226]]

Target = [[-4799187199, 40526618100], [-568324800, 4799204776]]

For this instance, the absolute determinant of every generator is the same integer B>1, while |det(Target)|=B^3. Consequently every valid word has exactly 3 labels. Return exactly 3 labels in multiplication order. Repetition is allowed; generator indices are 0-based; list order is significant.

Give your final answer inside <answer></answer> tags as a JSON list of quoted generator labels.
Example format: <answer>["g00","g01","g02"]</answer>
Output nothing else inside the tags.
```

The answer is `<answer>["g00","g03","g03"]</answer>`.
`verify(inst, inst["answer"])` returns `(True, "ok")`; deleting the last label returns
`(False, "wrong word length: determinants require 3 labels, got 2")`. A person can
solve this demo on paper by checking at most `4^3=64` words, or much faster by finding
the affine coordinate.

## Caveats

This is a deliberately structured subset of the paper’s general membership problem.
Software that tests affine collinearity solves it quickly; the measured million-state
MITM gap applies only when that structure is missed. The `0/200,000` guess rate is for
uniform length-10 words, not for an expert prior informed by matrix entries. The panel
does include the formerly fatal integral-left-quotient attack, but did not implement
the paper’s full canonical-automaton EXPSPACE procedure, an SMT encoding, or lattice
reduction. Large exact divisions are part of the 181-operation compact route, so some
no-tool failures may reflect arithmetic reliability as well as failure to see the
change of variables. The canonical key covers generator relabelling, both determinant
signs of unimodular conjugation, their composition, and transposition with word
reversal; it is not a complete invariant for arbitrary semigroup isomorphism.
