## What the family asks

The source is Acri and Bonatto, [*Skew braces of size
pq*](https://arxiv.org/abs/1908.03228). An instance displays regular subgroups of
the holomorph of the paper's nonabelian group
`M = Z_p semidirect_g Z_q`. Each subgroup is represented by shuffled,
additive-automorphism-conjugated generators and redundant products. The solver must
identify the paper's class `A_mu` induced by every subgroup. The answer is checked
by exact modular arithmetic: Theorem 3.12 gives
`d*(mu-1) = 1 (mod q)`, and the instance's class residues must also be values of
one promised nonconstant affine function on its displayed field coordinates.

Section 1 and Theorem 1.3 give the regular-subgroup/skew-brace correspondence.
Section 2 defines `M` and its automorphisms. Lemma 3.10, Proposition 3.11, and
Theorem 3.12 give the exact trivial-kernel regime and the formula used here.

## Why this is Track B

The paper is a complete classification, so Track A would be false. The executable
reference algorithm scans all `q-1` classes for two anchor components and then
evaluates the stated affine function. Its complexity is `O(q+c)`; at the hard
preset it performs 20,000,263 exact operations and averaged about 1.3 seconds over
eight audit seeds. The compact route recognizes that additive-automorphism
conjugation preserves the relevant projection, obtains two classes with Euclidean
inversion, and evaluates the affine function at the other coordinates. It averaged
258 exact operations and used 254 on the audited shipping seed.

The easy mathematical regimes are deliberately excluded. Proposition 3.1 says
that `p` not congruent to `1 mod q` has only the trivial brace, and Theorem 3.4
leaves only one nontrivial cyclic-type brace. This family instead uses the
nonabelian, trivial-kernel classes of Theorem 3.12.

## Worked demo

This is the complete rendering of `make_instance(seed=0, **DIFFICULTY["demo"])`:

```text
Skew-brace class identification from regular holomorph subgroups

Let p=11, q=5, and g=4.  These are primes p>q, q divides p-1,
and g has multiplicative order q modulo p.  Every first coordinate below
is reduced modulo p and every second coordinate modulo q.

Define the group M on pairs [n,m] by
  [n,m] + [s,t] = [n + g^m*s (mod p), m+t (mod q)].
For 1<=i<p and 0<=j<p define the automorphism phi_(i,j) by
  phi_(i,j)([n,m]) = [i*n + j*S_m (mod p), m],
where S_m=(g^m-1)/(g-1) modulo p (division means multiplication by
the modular inverse).

An element [a,b;i,j] of Hol(M)=M semidirect Aut(M) acts on x in M as
  x |-> [a,b] + phi_(i,j)(x).
For each component r, let G_r be the subgroup generated by its displayed
unordered records.  The data guarantee that G_r is regular: for every
x in M there is a unique [x;f_x] in G_r whose translation part is x.
It induces a skew-brace operation x circle_r y = x + f_x(y).

For an integer mu with 2<=mu<=q, A_mu denotes the skew brace on M with
  [n,m] circle_mu [s,t] =
      [g^t*n + (g^mu)^m*s (mod p), m+t (mod q)].
Two induced braces count as the same class when an additive automorphism
phi_(i,j) is an isomorphism, meaning phi_(i,j)(x circle_r y) equals
phi_(i,j)(x) circle_mu phi_(i,j)(y) for every x,y in M.
Interpret the class label q as residue 0 modulo q.  Each component r has
a displayed field coordinate T_r.  There are fixed residues U and nonzero
V such that residue(mu_r) = U + V*T_r (mod q) for every component.
No class residue is 1.  For a single component this affine promise is vacuous.

There are 1 components, indexed 0 through 0:
  component 0 (T_0=0):
    [4,0,1,1]
    [0,3,4,0]

Find the unique class label mu_r for every component r.  Return one
JSON list [mu_0]
in component-index order.  Every entry is an integer in the inclusive
range 2..q, and the entries are guaranteed (and required) to be pairwise
distinct.  Their residues must follow the promised affine relation.
There are no repeated entries and indexing is zero-based.

Give your final answer inside <answer></answer> tags, as a JSON list
of exactly the stated length.
Example of the required syntax: <answer>[2]</answer>
Output nothing else inside the tags.
```

The answer is `[3]`. `verify(demo, [3])` returns `(True, "ok")`, while
`verify(demo, [2])` returns `(False, "wrong A_mu class at component 0")`.
A person can solve this demo on paper by testing the four possible classes.

## Caveats

This family is easy with the displayed Theorem 3.12 relation, a CAS, GAP/Magma,
or a short program; that is the Track B claim, not a hidden limitation. The
guess probability is uniform over valid affine functions on the displayed
coordinates, conditioned to avoid residue 1. It does not model a group theorist's
prior, and 0/200,000 is an empirical upper-resolution result rather than an exact
density measurement (the exact valid-answer count is one).

No generic group-isomorphism package or independent GAP/Magma implementation was
run. The canonical key is complete for this generator's coordinate/subgroup pairs
under generator reorder, redundant products, additive-automorphism conjugation,
and component-list reorder; it is not a canonical form for arbitrary skew braces.
An earlier 20-independent-component version was solved by the oracle pool and was
discarded; the present affine-coordinate version has not been oracle-tested because
the key quota failed. Local correctness must not be mistaken for a hardness verdict.
